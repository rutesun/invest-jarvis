# Portfolio Monitor

포트폴리오 모니터링 - KIS API 실시간 보유종목 조회 + 분석

## Usage

```bash
uv run jarvis portfolio
```

## Requirements

```bash
# .env 파일 필요
KIS_APP_KEY=...
KIS_APP_SECRET=...
KIS_ACCOUNT_NO=...
```
