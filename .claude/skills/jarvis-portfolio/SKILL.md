# Portfolio Monitoring

KIS API 기반 포트폴리오 모니터링

## Usage

```bash
uv run jarvis portfolio
```

## What it does

- 보유 종목 현황 (KIS API)
- 각 종목별 기술적 분석
- 최근 뉴스 요약
- 수익률 추적

## Requirements

- KIS_APP_KEY
- KIS_APP_SECRET
- KIS_ACCOUNT_NO

## Example

```bash
uv run jarvis portfolio
```
