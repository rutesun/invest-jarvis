# ADR-0001: Reduce 스테이지에서 DuckDuckGo 뉴스 검색 제거

**상태:** 수락
**날짜:** 2026-04-18

## 컨텍스트

Daily Report 파이프라인의 Reduce 스테이지에서 테마별로 DuckDuckGo 뉴스를 검색하여 LLM 분석에 포함시키고 있었다. 테마 수가 10~30개이므로 매 실행마다 동일 수의 외부 API 호출이 발생했다.

문제점:
- DuckDuckGo API가 불안정하여 간헐적 실패 발생
- 검색 결과 품질이 일관되지 않음 (한국어 테마로 검색 시 관련 없는 결과)
- 텔레그램 채널 메시지 자체가 이미 리서치 기관의 분석을 포함하고 있어 추가 뉴스의 부가가치가 낮음

## 고려한 옵션

### 옵션 A: 뉴스 검색 유지 + 재시도/폴백 강화
- 장점: 외부 뉴스로 텔레그램 데이터 보완
- 단점: 근본적 품질 문제 미해결, 외부 의존성 유지, 실행 시간 증가

### 옵션 B: 뉴스 검색 제거
- 장점: 외부 의존성 제거, 실행 안정성 향상, 코드 단순화
- 단점: 텔레그램에 없는 뉴스를 놓칠 수 있음

## 결정

옵션 B 채택. 텔레그램 채널 데이터만으로 Reduce 분석을 수행한다.

## 결과

- `ddgs` import 및 `_search_news()` 함수 제거
- `REDUCE_USER_PROMPT`에서 `{news_articles}` 템플릿 제거
- Reduce 스테이지 실행 시간 단축 (외부 API 호출 제거)
- 향후 뉴스 보강이 필요하면 별도 스테이지로 추가하는 것을 검토
