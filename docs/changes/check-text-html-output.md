# Change Record: check 텍스트와 차트 HTML 출력

**Status**: Merged
**Date**: 2026-11-06
**PRs**: [#65](https://github.com/rutesun/invest-jarvis/pull/65)
**Type**: feat

## Why

관찰 이력을 날짜순으로만 읽으면 잠깐 회복한 뒤 다시 이탈한 종목의 현재 상태를 파악하기 어려웠습니다. 기본 텍스트에 더해 같은 분석 결과와 기술 차트를 한 파일에서 검토할 수 있도록 HTML 출력을 제공합니다.

## What

- 현재 유효 상태와 최근 20개 응답 거래일의 흐름을 연결하고 같은 회복의 종료·확인 중복을 합칩니다. 과거 청산 조건과 오늘 신규 매매 지시를 구별합니다.
- `check ... --html`은 텍스트 출력 후 `tmp/reports/check-<시각>-<고유ID>.html`에 저장하고 절대경로·파일 링크를 출력합니다. `--html PATH`와 `--html=PATH`로 경로를 지정할 수 있습니다.
- 기존 `analyze` 기술 차트와 CSS를 단일 HTML에 내장합니다. 차트 위에는 추세·가격 위치·구조·cRSI·거래량, 이동평균 네 개를 요약하고 수치의 방향에 맞춰 색을 적용합니다.
- `현재 상태`는 핵심 세 항목과 기준일을 먼저 보여줍니다. 날짜별 경과·추가 현재 상태·지난 관찰은 펼쳐 확인하며 잠정·미평가 경고는 기본 화면에 남깁니다.
- 차트 아래에는 전략별 판단·독립 수량 카드와 Quality 5일 선 그래프·4축 막대를 제공합니다.
- 명시 경로의 기존 파일은 `--force`로만 교체합니다. 저장 실패 시 기존 파일을 보존하고, 일부 종목 실패 시 성공 결과와 실패 사유를 함께 저장합니다.

## Before / After

```bash
# 기본 텍스트
uv run jarvis check ALAB 161890

# 텍스트와 HTML 자동 저장·파일 링크
uv run jarvis check ALAB 161890 --html

# 저장 경로 지정
uv run jarvis check ALAB 161890 --html reports/check.html
```

예를 들어 회복 → 재이탈 → 청산 조건의 이력은 `현재 상태: 150일선 청산 조건 충족 후 미회복`으로 요약하고, 각 날짜는 해당 상태의 경과에서 확인합니다.

## Impact

HTML 옵션을 생략하면 기본 텍스트만 출력하고 보고서 파일·폴더를 만들지 않습니다. HTML 요청 시 로컬 차트 생성 비용이 추가되며 브라우저는 자동으로 열지 않습니다. 파일에는 차트·스타일이 내장되어 외부 CDN이나 서버가 필요하지 않습니다. 종목 실패·저장 실패는 exit 1이며 차트만 실패하면 경고와 분석 결과를 남깁니다.

## Constraints

- 기존 Quality·Technical Score·전략 조건·독립 수량·직렬화 의미를 보존합니다. HTML 때문에 뉴스·LLM 호출이나 분석 결과 cache를 추가하지 않습니다.
- 기본 텍스트의 현재 상태·관찰 흐름과 기존 상세 출력은 유지합니다. 서로 다른 전략의 수량은 합산하지 않습니다.
- HTML 구조·내장 이미지·표시 경계는 자동 검증했습니다. 실제 브라우저·모바일·인쇄 레이아웃 검증은 미완료입니다.
- 구조화 가격·이동평균은 종목 통화에 맞춥니다. 상세 technical 진단 원문에는 국내 금액에도 기존 `$` 기호가 남을 수 있습니다.
