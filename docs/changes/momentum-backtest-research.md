## Why

외부 사양(단계형 모멘텀 매매 시스템 룰 v0.4/v0.5)을 jarvis에 반영하기 전에, 어떤 규칙이 실제로 성과를 내는지 데이터로 골라낼 필요가 있었다. 대가 방법론(Minervini·O'Neil·Weinstein)을 출발점으로 두고, 사용자 스타일(최소 2주 이상 보유, 초단기 회전 없음)에 맞는 규칙만 남기는 것이 목표였다.

## What

1. **백테스트 실험 스크립트 (`src/backtest/`)**: preset 비교, 베타·섹터 행렬, 홀드아웃, walk-forward, 시장 필터, 진입 품질, 적응형 필터, 추격 거리·국면, v0.4 레시피 전체, v0.4 조각 결합, 과거 1년 베타 관문, 부분매도, 과열 청산 격자, 새 기간 검증, 진입 타이밍 비교. 모두 독립 실행 스크립트이며 기존 모듈·CLI·파이프라인을 import하거나 변경하지 않는다.
2. **실험 결과 문서 (`docs/backtest/`)**: `README.md`(실행법·preset 정의·공통 한계), `results-log.md`(실험 1~23 결과와 확정 시스템 v1→v3).
3. **설계 문서**: `docs/trading-system-materials-recipes-design.md`(재료/레시피/상태 3층), `docs/trading-system-implementation-design.md`(구현 구조), 원문 `docs/references/trading_system_rules_v0.4.md`, `v0.5.md`.

## 확정 시스템 v3 (현재 기준)

```
대상:  필터 없음
진입:  S 상승 30주선 위 + 50일 신고가 돌파 + 거래량 1.4배
       D 200일선 아래 바닥에서 단기 추세 전환 + 20일 신고가 또는 50일선 회복
청산:  30주선 2일 연속 아래 마감, 또는 30주선−1R 아래 마감
과열:  50일선 대비 +40% 이격 뒤 20일선 이탈 시 전량 매도 → 20일선 회복 시 재매수
성적:  미사용 기간(2016~2021) 370회 평균 1.02R, 95% 구간 0.7~1.3R
```

## 주요 결론

- 규칙을 고르는 데 쓰지 않은 2016~2021년에서도 뼈대(S+D+새 청산)가 양(+)의 성과(큰 승자 10건 제외해도 0.64R).
- 폐기: v0.4 레시피 전체(보유 4일, 최악 −8.6R), Minervini 정밀 진입 필터(과필터), 촘촘한 청산·본전 손절·50/100일선 부분매도(큰 승자 절단), 지수 추세 시장 필터(효과 없음), 고베타 관문(새 기간에서 효과 없음), 150일선 첫 돌파 단독 진입.
- 정정: 초기 실험들은 지표 준비 기간 때문에 실제 매매가 2022년 중반 이후만 잡혀 절대값이 부풀려져 있었다(1.64R → 온전한 기간 1.00R).

## Impact

- 사용자 기능(check/analyze/brief/screen/report) 동작 변화 없음. 리서치 스크립트와 문서만 추가.
- 기존 테스트에 영향 없음(기존 코드 미수정).

## Constraints

- 생존편향: 현재 상장 종목만 사용(무료 데이터로 상장폐지 종목 확보 어려움). 실제 성과는 더 낮을 수 있다.
- 거래비용: 매수·매도 각 0.1% 반영 시 0.01~0.03R 감소 수준으로 확인.
- 이익 쏠림과 연도별 기복이 크다(12년 중 4년 마이너스).
- 스크립트는 실험용으로 골든 테스트가 없다. 엔진화 시 매매 목록을 fixture로 고정해 동등성 테스트를 붙인다.
