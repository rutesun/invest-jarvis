## Why

volume 컴포넌트는 상승일 거래량 급증을 1.5x(+5)·2.0x(+15)로 채점하는데, 그 사이 아래 구간(vol_ratio 1.0~1.5x)은 0점이었다. 이 때문에 **+40%대 거래량을 동반한 신고가 돌파가 "거래량 신호 없음(0점)"으로 사라지는 사각지대**가 있었다. 실제 사례: 제닉(123330) 8/26 돌파일 vol_ratio 1.42x — 눌림 구간(12~15만 주) 대비 3배 이상(53만 주)으로 늘었는데도 1.5x 문턱을 근소하게 못 넘겨 0점 처리됐다.

## What

1. **완만 증가 티어 추가 (`components/volume.py`)**: 상승일 + `1.2x < vol_ratio ≤ 1.5x` 구간에 **+3점**과 `"거래량 완만 증가 (강세 확인)"` signal/evidence를 부여. 급증 티어(1.5x=+5 / 2.0x=+15)와 Pocket Pivot·Tennis/Egg·Power Gap 로직은 건드리지 않고 **기존 0점 구간에만 가점**해 파급을 최소화했다. 급증→완만→중립으로 채점 티어가 연속된다.
2. **상승 확증에 한정**: 하락일에는 가점하지 않는다(완만 증가는 상승 확인 개념). 1.2x 이하는 기존대로 0점.
3. **임계값 상수화 (`components/patterns.py`)**: `PatternThresholds.VOLUME_MODERATE_MULTIPLIER = 1.2` 추가. 매직넘버 대신 상수로 조정 가능.

## Before / After

```
Before: 제닉 8/26 (상승, vol_ratio 1.42x) → volume 컴포넌트 0점, signal/evidence 없음
        → 출력상 "거래량 신호 없음"으로 오인
After:  제닉 8/26 → volume 컴포넌트 +3점
        signal "거래량 완만 증가 (강세 확인)" / evidence "거래량 532,649 / 20일평균 375,616 = 1.4x"
```

## Impact

- check/brief/analyze에서 완만한 거래량 증가를 동반한 상승일이 소폭 가점(+3)과 함께 근거 문구로 표면화된다. 기존에 0점으로 묻히던 돌파 확증이 보인다.
- 가점 폭이 작아(+3) 대부분 종목의 최종 verdict를 뒤집지 않는다. 경계 사례에서만 미세하게 상향.

## Constraints

- **급증 임계값(1.5x/2.0x)과 기존 패턴 로직은 불변** — 파급을 0점 구간에만 국한. 골든 테스트(전 경로) 및 기술/스코어링 테스트 312건 통과로 회귀 없음 확인.
- vol_ratio가 20일 **평균**(mean) 기반이라 단일 대량거래일이 분모를 부풀려 비율을 낮게 표시하는 근본 이슈는 이번 범위에서 다루지 않았다(예: 중앙값 기반 baseline). 별도 후속 과제.
