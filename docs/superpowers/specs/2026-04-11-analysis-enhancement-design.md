# Analysis 개선 설계서

**작성일**: 2026-04-11  
**상위 문서**: [invest-jarvis 비전 설계서](2026-04-11-invest-jarvis-vision.md)  
**커맨드**: `jarvis analyze <TICKER>` (기존 커맨드 확장)

---

## 목표

`jarvis analyze`에 **공시 분석(SEC/DART)**을 추가하여,
기술적 분석 + 기본적 분석 + 뉴스 + 공시를 통합한 멀티팩터 딥다이브로 격상.

---

## 현재 상태 vs 목표

| 팩터 | 현재 | 추가 |
|------|------|------|
| 기술적 분석 | 5전략 시스템 (Trend, Oscillator, Divergence, Disparity, Risk) | - |
| 기본적 분석 | PER/ROE/배당 (Plan 4) | - |
| 뉴스 | DDGS 감성 분석 | - |
| **공시** | **없음** | **SEC EDGAR + DART** |
| **수급** | **없음** | **외인/기관 순매수 동향** (한국주식) |

---

## 공시 분석 모듈 설계

### SEC EDGAR (미국 주식)

**조회 대상:** 최근 3개월의 10-Q, 8-K (최대 5건)

**파이프라인:**
```
ticker
  ↓
SEC company_tickers.json → CIK 변환 (6시간 캐시)
  ↓
/submissions/{cik} → 최근 공시 리스트
  ↓
filing_date 기준 내림차순 정렬
  ↓
10-Q, 8-K 필터링
  ↓
DisclosureItem 리스트 (form_type, date, description, url)
```

**핵심 추출 정보:**
- 8-K: 임시 이벤트 — 실적 발표, M&A, 경영진 변경, 주요 계약
- 10-Q: 분기 재무 — 매출/영업이익 변화, 리스크 팩터 업데이트

### DART (한국 주식)

**조회 대상:** 최근 3개월, 키워드 필터링

**파이프라인:**
```
ticker (6자리 코드)
  ↓
OpenDART API → corp_code 변환
  ↓
/api/list.json → 최근 공시 리스트
  ↓
키워드 필터링 + 중요도 스코어링
  ↓
상위 5건 선정
```

**키워드 필터링 (telegram 프로젝트 방식 계승):**

| 키워드 유형 | 키워드 | 가중치 |
|------------|--------|--------|
| 중요 | 계약, 수주, 실적, 매출, 영업이익, 투자, 유상증자, 자기주식, 소송, 내부자매도 | +1.0 |
| 저신호 | 사업보고서, 분기보고서, 반기보고서 (정기 보고서) | -1.0 |
| 수치 포함 | 조, 억원 등 금액 단위 | +0.5 |

→ 스코어 >= 1.0인 공시만 선택, 스코어 × 날짜 내림차순 정렬

### 수급 분석 (한국 주식)

**Naver 투자자별 매매동향:**
- 외인/기관/개인 순매수 금액
- 최근 5일 추이
- 순매수 방향 전환 감지

## analyze 파이프라인 통합

```
jarvis analyze AAPL
        ↓
  ┌─────────────────────────────┐
  │  병렬 데이터 수집              │
  │  ├─ 기술적 분석 (5전략)         │
  │  ├─ 기본적 분석 (PER/ROE/배당)  │
  │  ├─ 뉴스 검색 + 감성 분석       │
  │  ├─ 공시 조회 (SEC or DART)    │  ← 신규
  │  └─ 수급 데이터 (KR only)      │  ← 신규
  └─────────────────────────────┘
        ↓
  LLM 종합 해석 (모든 팩터 통합)
        ↓
  마크다운 리포트
```

**LLM 프롬프트에 추가되는 컨텍스트:**
```
## 공시 분석
최근 3개월 주요 공시:
1. [8-K] 2026-04-05: Q1 실적 발표 — EPS $2.50, 매출 $94.8B
2. [8-K] 2026-03-20: AI 칩 파트너십 체결 (계약 규모 $2B)
   URL: https://sec.gov/...

## 수급 동향 (한국주식만)
| 투자자 | 5일 순매수 | 방향 |
|--------|-----------|------|
| 외국인 | +850억 | 매수 전환 |
| 기관 | +320억 | 매수 유지 |
```

## 출력 형식 개선

현재 analyze 출력에 **공시 섹션** 추가:

```markdown
## 분석 리포트: AAPL

### 가격 & 기술적 분석
(기존과 동일)

### 기본적 분석
(기존 Plan 4 결과)

### 공시 분석                          ← 신규
최근 3개월 주요 공시 2건:
1. **[8-K] Q1 실적 발표** (2026-04-05)
   EPS $2.50 (컨센서스 $2.30 상회), 매출 $94.8B (+12% YoY)
   → 어닝 서프라이즈. AI 관련 매출 비중 확대 언급.

2. **[8-K] AI 칩 파트너십** (2026-03-20)
   → 자체 AI 칩 개발 가속. 기존 NVDA 의존도 감소 신호.

### 수급 동향 (한국주식)               ← 신규
외인: +850억 (5일 연속 순매수)
기관: +320억 (매수 전환)
→ Smart Money 유입 중

### 뉴스 감성 분석
(기존과 동일)

### 종합 인사이트                      ← 강화
투자 추천: 매수
근거:
- 기술적: 상승 추세 + 거래량 확인
- 기본적: PER 25.3x (업종 평균 28x 대비 할인)
- 공시: 어닝 서프라이즈 + AI 전략 가시화
- 수급: 외인/기관 동반 순매수
리스크: 미중 관세 리스크, RSI 과열 접근
```

## 의미있는 인사이트를 위한 추가 제안

### 1. 공시-가격 반응 분석
공시 발표일의 주가 반응을 함께 제시:
- 8-K 발표 다음날 주가: +3.2%
- "시장은 이 공시를 긍정적으로 평가"
→ 공시의 실질적 영향력을 객관적으로 보여줌

### 2. 컨센서스 비교
yfinance의 analyst recommendations/targets 활용:
- 애널리스트 평균 목표가 vs 현재가 → 업사이드 %
- 최근 목표가 변경 방향 (상향/하향 조정)
- 매수/보유/매도 비율

### 3. 동종업계 비교
같은 섹터 내 주요 경쟁사와 비교 테이블:
```
| 지표 | AAPL | MSFT | GOOGL | 섹터평균 |
|------|------|------|-------|---------|
| PER | 25.3 | 31.2 | 22.8 | 28.0 |
| ROE | 147% | 39% | 27% | 71% |
| 차트신호 | 매수 | 중립 | 매수 | - |
```
→ 상대적 매력도 판단에 도움

### 4. 이벤트 캘린더
해당 종목의 향후 예정 이벤트:
- 실적 발표일 (D-14)
- 배당락일
- 옵션 만기일
- 예정된 컨퍼런스/IR
