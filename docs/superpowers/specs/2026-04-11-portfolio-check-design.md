## 목표

내 보유 종목 각각에 대해, **지금 알아야 할 것들을 종합적으로 정리**.
현재의 `portfolio` 커맨드(기술적 분석 + 뉴스 요약 수준)를 
뉴스·공시·텔레그램·기술적 분석을 통합한 **멀티팩터 브리핑**으로 격상.

## 현재 상태 vs 목표

| 항목 | 현재 (`portfolio`) | 목표 |
|------|-------------------|------|
| 데이터 소스 | KIS API 보유종목 + 기술적 분석 + 뉴스 | + Telegram + 공시(SEC/DART) |
| 분석 깊이 | 기술적 신호 요약 | 이벤트 랭킹 + 패턴 인식 + 종합 인사이트 |
| 점수 체계 | 없음 | 차트 스코어(0-60) + 뉴스·공시 스코어(0-40) = 종합 100점 |
| 출력 | Rich 테이블 | 종합 점수 기반 정렬 + 종목별 마크다운 브리핑 |
| 차트 | 없음 | mplfinance 캔들차트 (SMA, SuperTrend, MACD, RSI) |

## 데이터 수집 파이프라인 (종목별, 병렬)

```
KIS API: 보유종목 리스트
        ↓
종목별 병렬 수집 (semaphore=6)
  ├─ 기술적 분석 (기존 5전략)
  ├─ 뉴스 검색 (DDGS, 최근 72h)
  ├─ 공시 조회 (SEC/DART, 최근 3개월)
  ├─ Telegram 검색 (CSV grep, ticker/회사명)
  └─ 수급 데이터 (Naver flow, 한국주식만)
        ↓
이벤트 랭킹 + 차트 스코어링
        ↓
종합 인사이트 (LLM)
        ↓
마크다운 리포트
```

### 데이터 소스 상세

#### Telegram 데이터
- CSV 파일에서 ticker/회사명/관련 키워드로 grep
- 최근 7일 데이터 검색 (일별 CSV 파일)
- 채널 출처 포함하여 근거 추적 가능

#### 공시 자료
- **SEC EDGAR (미국)**: 최근 3개월 10-Q, 8-K
  - sec-edgar-api 활용
  - ticker → CIK 변환 (캐시)
- **DART (한국)**: 최근 3개월 공시
  - OpenDART API 활용
  - 키워드 필터링: 계약, 내부자 매도, 사업보고서
  - 중요도 스코어링: 실적/수주/계약 관련 키워드 +1.0, 정기보고서 -1.0

#### 수급 데이터 (한국 주식)
- Naver 투자자별 매매동향: 외인/기관/개인 순매수
- 최근 5일 순매수 추이

## 분석 레이어

### 1. 이벤트 랭킹

수집된 뉴스 + 공시 + 텔레그램 데이터를 **중요도 순으로 정렬**.

**중요도 계산:**
- 기본 가중치: 공시(1.4) > 뉴스(1.0) > 텔레그램(0.8)
- 키워드 매칭: 실적/가이던스/수주/합병/증자/자사주/소송 → 각 +0.5
- 최대 4.0 캡

**중복 제거:**
- 뉴스 제목에서 앵커 토큰 4개 추출 → 이벤트 유형 prefix → 클러스터 키
- 같은 클러스터 내 가장 중요도 높은 항목만 대표로 선택

**상위 5건 선정:**
```
[공시] SEC 8-K: Q1 실적 발표 — EPS $2.50 (예상 $2.30 상회)  ⭐⭐⭐⭐
[뉴스] "AAPL, 신규 AI 칩 파트너십 발표" — Reuters  ⭐⭐⭐
[텔레그램] "AAPL 관련 흥미로운 움직임" — @channelname  ⭐⭐
```

### 2. 기술적 분석 점검

기존 5전략 시스템 + 추가 패턴 인식:

**차트 스코어 (0-60):**
```
base = 종합평가 점수 (강력매수 60, 매수 52, 중립 40, 매도 26, 강력매도 16)
conf_bonus = (신뢰도/100) * 12
pattern_bonus = min(4, 감지된 패턴 수)
warn_penalty = min(4, 경고 수)
chart_score = clamp(0, 60, base + conf_bonus + pattern_bonus - warn_penalty)
```

**차트 메트릭 (한 줄 요약):**
- 등락률, 거래량 강도(거래량/SMA20 비율), 변동폭, 슈퍼트렌드 지지선

**차트 렌더링 (mplfinance):**
- 캔들차트 + SMA(20/50/120/150/200) + SuperTrend + 매수/매도 시그널
- Volume + VOL_SMA_50
- MACD(12,26,9)
- cRSI
- Stage2 구간 하이라이팅

### 3. 종합 인사이트 (LLM)

뉴스·공시 스코어(0-40)와 차트 스코어(0-60)를 합산한 **종합 점수(0-100)** 기반.

LLM에게 전달하는 컨텍스트:
```
- 차트 스코어 & 메트릭 (기술적 상태)
- 이벤트 랭킹 상위 5건 (뉴스/공시/텔레그램)
- 수급 데이터 (외인/기관 동향)
- 기본적 분석 (PER/ROE/배당)
```

LLM이 생성하는 인사이트:
- **현재 상태 판단**: 매수/매도/홀드 + 근거 1-2줄
- **핵심 리스크**: 현재 가장 주의할 점
- **다음 주목 이벤트**: 실적 발표일, 공시 예정 등

## 의미있는 인사이트를 위한 추가 제안

### 1. 변화 감지 기반 알림
매번 portfolio를 돌릴 때마다 전회 대비 **변화된 것만 강조**:
- 새로운 공시가 나왔는가?
- 기술적 신호가 바뀌었는가? (매수 → 중립 전환 등)
- 외인/기관 수급 방향이 바뀌었는가?
→ 이전 실행 결과를 로컬에 저장하여 diff 계산

### 2. 위험 종목 우선 표시
종합 점수 기반 정렬 외에, **긴급 주의 종목** 별도 섹션:
- 차트 스코어 < 25 (매도 신호)
- 손절 라인 근접 (현재가가 2-ATR 손절선 이하)
- 부정적 공시 (소송, 규제, 내부자 매도)
→ 리포트 최상단에 경고 배너로 표시

### 3. 포트폴리오 전체 관점
개별 종목 분석 후, **포트폴리오 레벨 인사이트** 추가:
- 섹터 집중도: "포트폴리오의 60%가 반도체 섹터에 집중"
- 상관관계 리스크: "보유 종목 3개가 같은 테마에 노출"
- 전체 포트폴리오의 Bull/Bear 비율

### 4. 실적 캘린더
보유 종목의 **다가오는 실적 발표일** 표시:
- yfinance의 earnings_dates 활용
- 실적 발표까지 D-7 이내인 종목 강조
- 어닝 서프라이즈/쇼크 히스토리 제공 (최근 4분기)
