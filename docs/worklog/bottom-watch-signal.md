## (2026-08-24 17:15) [Pivot] bottom_watch 트리거 폐기 → 바닥 사례 귀납 수집으로 전환
- 이전 접근: 하락추세 + (RSI+cRSI 강세 다이버전스, score≥35) + 최근 15거래일 과매도 훅(cRSI<30)을 AND로 묶어 역추세 바닥 관찰 플래그를 켠다. 엘앤에프·실리콘투 두 종목 as-of 백테스트로 설계.
- 전환 이유: 독립 리뷰 2건이 표본 편향·과적합·성공기준 부재를 지적 → 편향 없는 표본으로 §6 검증 실행. 결과 트리거가 시드 2종목 외 거의 발화 안 함(대형주 30종목×3년 1건, 변동성주 6종목×1년 0건). 하네스는 시드 케이스를 정확히 재현하므로 버그 아님. 근본 원인: 하락추세+과매도 훅 후보일(종목당 15~50일)에 divergence가 거의 안 뜸(후보일 최대 divergence=0) — 다이버전스 피벗과 과매도 훅의 시점이 좀처럼 안 겹침. 2종목·3시점으로 파라미터 고정한 것이 과적합.
- 새 접근: 신호를 먼저 정의→검증하는 순서를 버리고, 편향 없는 바닥 매수 사례를 10개+ 수집해 그 시점의 지표 상태에서 공통 패턴을 귀납 추출한 뒤 신호를 정의한다. 사용자 보유/관심 사례부터 수집 예정.
- ADR 후보? no (음성 결과 + 방향 전환, 스펙에 기록됨)

## (2026-08-25 09:31) [Decision] 방향 재구성 — "바닥 신호"에서 "턴어라운드 발굴 → 소량 테스트 → check 확인" 깔때기로
- 맥락: 사례 6종목(엘앤에프·실리콘투·PGY·HOOD·삼성전기·삼성전자) 분석 결과, 사용자 실제 목표는 "바닥 잡기"가 아니라 **"추세 확인 후 이격이 벌어지기 전 진입"**. 그러나 supertrend 전환 시점 이격도는 이후 수익률을 예측 못 함(저이격도 실패·고이격도 대박 공존) — 이격은 예측이 아니라 진입 리스크(손절거리)만 정의. Ouroboros 인터뷰(/ouroboros:interview)로 방향 가치 전면 재검토.
- 후보: A) 이격 기반 진입 리스크 게이트(내 초안) / B) 늦은 발굴 진입 판단(#1) / C) 턴어라운드 발굴 스크리너(#2) / D) 불필요(check+육안으로 충분)
- 선택: **C를 우선**, 전체는 깔때기 구조. 이유: 사용자가 "소량 테스트로 구매"라고 명시 → 정밀도(precision)가 아니라 재현율(recall)만 필요 → bottom_watch를 죽인 "승패 사전 구분 불가" 벽이 사라짐. 여럿 소량 진입 후 기존 check(추세 확인)가 증량/손절을 담당.
- 턴 정의: 4개 마커(급락후 과매도반등 / 20·50일선 재탈·지지 / 거래량 수반 양봉 / 저점 높이기)를 **AND가 아니라 점수화·순위**(AND면 bottom_watch처럼 0건). 거래량이 유일한 오실레이터 밖 독립축.
- 남은 검증 관문: 턴어라운드 스코어 상위 바스켓의 신호 후 수익률 분포가 나이브 기준선("3개월 저점 대비 10% 반등한 아무 종목")을 넓은 유니버스에서 이겨야 함. 못 이기면 폐기(bottom_watch와 동일 규율).
- 기각: A(예측력 없음이 실측 확정, 게이트 단독은 가치 약함), B(점진적·check+이격 포장 수준), D(사용자가 발굴·타이밍 보강을 명시 요구).
- 한 줄 goal: 기존 스크리너에 '턴어라운드 발굴 모드'를 추가—4마커 점수화(AND 아님)로 바닥 턴 후보를 순위 표면화하고, 상위 후보 소량 테스트→check 확인 시 증량/이탈 시 손절로 이어지는 깔때기의 입구를 만든다.
- ADR 후보? no (아직 검증 관문 통과 전 · 스펙화 전)

## (2026-08-25 later) [Decision] 턴어라운드 개별종목 신호로 확정 · 광역 발굴은 별도 과제로
- 맥락: 턴어라운드 신호를 check/screen/brief에 배선 후, screen 발굴이 유니버스 미스매치(네이버/순매수 리더 = 이미 오른 종목)로 변별력 낮음을 실측. 사용자 가설("외국인·기관 순매수로 바닥 매집을 잡을 수 있지 않나") 검증.
- 검증(실데이터):
  - KIS 순매수 순위 API가 화면코드 16174(오류)+정렬 파라미터 누락으로 rt_cd 에러 → 항상 0건 조용히 반환하던 버그 발견·수정(16449 + FID_RANK_SORT_CLS_CODE, rt_cd 가드). 외국인/기관 각 30종목 정상.
  - '저점 근접(≤15%)+매집 전환' 프로토타입: 순매수 리더 30종목 중 26개가 이미 +15% 초과 상승(제외), 저점권 4개는 전부 은행·전력·인프라 블루칩, 매집전환 1개(맥쿼리인프라, 인프라펀드). 성장주 V턴은 없음.
- 결론: 순매수 리더보드는 "바닥 발굴"의 잘못된 입구(리더에 뜰 땐 이미 상승). 진짜 바닥 발굴은 "넓은 유니버스 저점 근접 → 매집 시작 탐지" 순서여야 하며, 이는 전종목 마스터/무거운 스캔이 필요해 별도 과제로 분리.
- 선택: 현재 성과(개별 종목 턴어라운드 신호 + KIS 버그 수정) 확정·박제. 광역 발굴은 ROADMAP 후속.
- ADR 후보? no
